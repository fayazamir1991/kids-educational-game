# بازبینی معنایی صداهای حیوانات

این گزارش، بازبینی نسخهٔ `b12c0d6` و پیشنهاد قطعه‌های جایگزین است. سنجش رمزگشایی، بلندی صدا، SHA256 و مجوز به‌تنهایی ثابت نمی‌کند صدای هدف واضح و درست است؛ گزارش قبلی این تفاوت را به‌اندازهٔ کافی روشن نمی‌کرد.

## روش و محدودیت

همهٔ ۱۷ فایل با **Google YAMNet** از مخزن رسمی TensorFlow بررسی شدند. مدل رویدادهای صوتی AudioSet را در پنجره‌های ۰٫۹۷۵ ثانیه‌ای، با فاصلهٔ ۰٫۴۸۷۵ ثانیه، امتیاز می‌دهد. از قطعهٔ کامل و هر پنجره، امتیاز صدای هدف و رویدادهای مزاحم استخراج شد. فایل‌ها برای بررسی به صوت تک‌کانالهٔ 16 kHz تبدیل شدند؛ خود فایل‌های بازی در این مرحله تغییر نکردند.

- مدل از commit ثابت `29adb0afae1b0f6bcc37a60d0534b650119583ea` در [tensorflow/tflite-support](https://github.com/tensorflow/tflite-support) گرفته شد.
- SHA256 مدل: `10c95ea3eb9a7bb4cb8bddf6feb023250381008177ac162ce169694d05c317de`.
- دریافت مدل از HTTPS عادی انجام و هش آن بررسی شد؛ بررسی TLS یا checksum غیرفعال نشد.
- این بررسی **شنیدن انسانی نیست** و هیچ‌کدام از نمره‌ها تأیید قطعیِ تشخیص حیوان یا مناسب‌بودن برای کودک نیستند. نمره‌های مدل احتمال کالیبره‌شدهٔ گونه نیستند.
- مدل برای میمون، الاغ و جوجه کلاسِ گونهٔ مستقلی ندارد. تشخیص عمومیِ «پرنده» یا «جیک‌جیک» هویت جوجه را ثابت نمی‌کند. صداهای مگس و زنبور نیز امتیازهای هم‌پوشان دارند و نباید در یک سؤال مقابل هم باشند.
- عنوان فایل و مجوز، مدرکِ هویت شنیداریِ همان قطعه نیستند. ضبط‌های محیطی یا نمونه‌های بازی‌های دیگر ممکن است نام درست و صدای آموزشیِ نامناسب داشته باشند.

## سیاست قرار گرفتن در سؤال

هر ضبطی که صرفاً نام یا منبع معتبری دارد نباید پاسخ یک سؤال آموزشی شود. برای انتشار اصلاحیه، نمونه‌های دارای شواهد مبهم یا نبود امکان تشخیص گونه باید از مجموعهٔ پاسخ‌ها کنار گذاشته شوند و برای بررسی بعدی در فهرست منابع باقی بمانند.

به‌ویژه **جوجه، میمون و الاغ** با ابزار فعلی تأیید گونهٔ قابل اتکا ندارند. نگه داشتن تصویر و منبعشان به معنی مجاز بودن استفاده در سؤال نیست. تا ضبطِ تک‌حیوانیِ روشن یا بازبینی شنیداری قابل اتکا فراهم نشده، پیشنهاد این گزارش این است که این سه مورد از سؤال‌ها کنار گذاشته شوند. برای زنبور و مگس نیز حتی با نمونهٔ وزوز قوی، هرگز سؤال تمایز میان این دو ساخته نشود.

مبنای ثبت بررسی باید SHA256 **همان فایل نهایی پخش‌شونده** باشد؛ تغییر فایل، برش یا پردازش تازه، نتیجهٔ بررسی قبلی را معتبر نگه نمی‌دارد. بررسی خودکار باید پس از انتخاب و پردازش نهایی دوباره اجرا شود و نتیجهٔ نسخهٔ قبلی به نسخهٔ جدید نسبت داده نشود.

مجوز مجموعهٔ ESC-50 از مجوز اصلیِ هر ضبط جداست؛ مدرکِ هر قطعه در فایل LICENSE نسخهٔ ثابت `33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6` موجود است و اطلاعیهٔ مجموعه باید حفظ شود. برای CC-BY، در جایی که نسخهٔ مجوز در منبع ذکر نشده، نسخه‌ای حدس زده نمی‌شود.

## اجرای دوبارهٔ ابزار بررسی

ابزار فقط گزارش تولید می‌کند و هیچ صدایی را خودکار تأیید، جابه‌جا یا اصلاح نمی‌کند. وابستگی‌های مدل برای توسعه‌اند؛ بازی هیچ مدل یادگیری ماشین یا نصب جدیدی در زمان اجرا نیاز ندارد.

```sh
python -m pip install --target /tmp/animal-audit-deps ai-edge-litert==2.3.0
PYTHONPATH=/tmp/animal-audit-deps python scripts/audit-animal-recordings.py \
  --download-model --output /tmp/animal-audio-review.json
```

برای مقایسهٔ گزینه‌ها، مسیر فایل‌ها را پس از نام اسکریپت بدهید. گزارش JSON شامل SHA256 هر فایل، امتیاز همهٔ رویدادها، پنجره‌های زمانی، رویدادهای مزاحم و هشدار نبود کلاس گونه است. هیچ وضعیت `approved` یا ادعای «همهٔ صداها شنیده و قطعی تأیید شدند» تولید نمی‌شود.

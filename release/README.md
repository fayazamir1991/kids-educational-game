# نسخهٔ ۳ — مجموعهٔ بازی‌ها

`kids-games-v3.zip` نسخهٔ جدید برنامهٔ مجموعه است. آن را دانلود و استخراج و `kids-games-v3.html` را با مرورگر باز کنید. صفحهٔ اول فهرست بازی‌هاست و فعلاً یک بازی دارد: «کی صدا کرد؟».

فهرست در حالت عمودی و افقی کار می‌کند. پس از انتخاب بازی، اگر گوشی عمودی باشد راهنمای چرخش نمایش داده می‌شود. در بازی و راهنمای چرخش، دکمهٔ برگشت به فهرست وجود دارد. برگشت، صدا و نوبت بعدی را متوقف می‌کند و ورود دوباره بازی تازه‌ای می‌سازد.

برای اجرای خود برنامه اینترنت و نصب ابزار توسعه لازم نیست. بخش صداها همان بازبینی نسخهٔ ۲ است: ۱۴ حیوان فعال، ۳ نمونهٔ معلق، بررسی ماشینی و بدون ادعای تأیید شنیداری انسانی. گزارش و مجوزها همراه بسته‌اند.

`little-farm.zip` هم به برنامهٔ مجموعهٔ نسخهٔ ۳ به‌روز شده است. `little-farm-v2.zip` برای نسخهٔ قبلیِ بازی مستقیم باقی می‌ماند؛ لینک‌های دارای commit قبلی فایل قدیمی می‌دهند.

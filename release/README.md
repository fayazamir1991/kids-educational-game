# نسخهٔ آمادهٔ بازی

فایل `little-farm.zip` شامل بازی تک‌فایلی با ۱۷ صدای واقعی حیوانات است. آن را دانلود و استخراج کنید؛ سپس `little-farm.html` را با مرورگر باز کنید و گوشی را افقی بگیرید. برای اجرای خود بازی نصب ابزار توسعه یا اتصال اینترنت لازم نیست.

پیش‌نمایش فایل در چت یا برنامهٔ مدیریت فایل ممکن است جاوااسکریپت بازی را اجرا نکند؛ فایل باید در مرورگر باز شود. منابع، مجوزها و نام ضبط‌کنندگان داخل بازی و پوشهٔ `licenses` فایل ZIP ثبت شده‌اند.

این بسته از `npm run build:standalone` ساخته شده است. بسته به‌همراه منبع پروژه نگهداری می‌شود تا دریافت بازی به سرویس دانلود محیط وابسته نباشد.

# نسخهٔ ۲ — بازبینی صداها

فایل `little-farm-v2.zip` نسخهٔ جدید است؛ آن را دانلود و استخراج کنید و `little-farm-v2.html` را با مرورگر باز کنید. گوشی را افقی بگیرید. نصب ابزار توسعه یا اینترنت برای خود بازی لازم نیست. نام «نسخهٔ ۲» در تنظیمات بزرگ‌ترها هم دیده می‌شود.

۸ صدای قبلی جایگزین یا دوباره برش داده شده‌اند. ۱۴ حیوان در سؤال‌ها فعال‌اند؛ جوجه، میمون و الاغ هنوز تأیید صوتی کافی ندارند و نه پاسخ‌اند و نه گزینهٔ انحرافی. همهٔ ۱۷ نمونه برای بررسی بزرگ‌ترها دکمهٔ شنیدن جداگانه دارند.

بازبینی معنایی با مدل رسمی Google YAMNet انجام شده است. شنیدن و تأیید انسانی در این محیط انجام نشده؛ نتایج، تضمین قطعی گونه یا وضوح برای کودک نیستند. گزارش و هش فایل‌ها در پوشهٔ review بسته آمده است. نمونهٔ شیر از آینهٔ دارای اعتباردهی Mixkit گرفته شده؛ دسترسی مستقیم Mixkit مسدود بود.

`little-farm.zip` نیز به همین نسخهٔ ۲ به‌روز شده است. لینک‌های دارای commit نسخهٔ قبلی همچنان فایل قدیمی را می‌دهند؛ برای این اصلاحیه از نام و لینک جدید استفاده کنید.

بسته از `npm run build:standalone` ساخته و پخش آن در مرورگر بدون شبکه آزمایش شده است. مجوز صداها و فونت در پوشهٔ licenses داخل ZIP حفظ شده است.

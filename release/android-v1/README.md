# باغ بازی‌های کوچولو — نسخهٔ آزمایشی اندروید ۱.۰.۰

`kids-garden-test-1.0.0.apk` قابل نصب و دارای امضای آزمایشی است. برنامه هشت بازی فارسی، اجرای محلی و بخش والدین دارد. حساب کاربری، تبلیغ، خرید درون‌برنامه‌ای و تحلیل‌گر ندارد.

اندروید ۸ یا جدیدتر و Android System WebView نسخهٔ ۱۰۵ یا جدیدتر لازم است. برای موتور قدیمی، راهنمای فارسیِ به‌روزرسانی نمایش داده می‌شود. خود بازی‌ها و ۱۴ صدای حیوان همراه APK هستند و به اینترنت نیاز ندارند.

این فایل برای بررسی روی گوشی است و با کلید نهایی ناشر امضا نشده است. برای نصب نسخهٔ نهایی با گواهی دیگر، ابتدا نسخهٔ آزمایشی را حذف کنید؛ ترجیحات محلی آن پاک می‌شوند.

`kids-garden-publication-1.0.0.zip` شامل APK و AAB انتشار **بدون امضا**، نشان برنامه، تصاویر معرفی، متن‌های فروشگاه، پیش‌نویس حریم خصوصی، مجوزها و راهنمای امضای ناشر است. فایل AAB مستقیم روی گوشی نصب نمی‌شود. فایل APK بدون امضا هم برای نصب یا بارگذاری آماده نیست.

صدای راهنمای گفتاری فارسی تا تأیید تلفظ و کیفیت فعال نشده است. راهنماهای تصویری، واکنش تمام‌صفحه، موسیقی پاسخ‌ها و صداهای واقعی حیوانات در دسترس‌اند. بررسی ماشینی صداها معادل تأیید شنیداری انسانی یا تأیید تشخیص‌پذیری برای کودک نیست.

پیش از انتشار عمومی باید اطلاعات واقعی ناشر و پشتیبانی، نشانی عمومی حریم خصوصی، شناسهٔ نهایی برنامه، امضای تحت مالکیت ناشر، آزمون روی گوشی و فرم‌های فروشگاه تکمیل شوند. هیچ بارگذاری در بازار یا گوگل‌پلی انجام نشده است. رمز، فایل کلید یا گذرواژهٔ امضا را در چت یا مخزن عمومی قرار ندهید.

راهنمای فنی و وضعیت بررسی در `docs/publishing-android.md` و `docs/store-readiness.md` موجود است. صحت فایل‌ها با `SHA256SUMS` قابل بررسی است.

# فایل‌های امضاشدهٔ بازار — ۱.۰.۰

- `kids-garden-1.0.0.aab`: بستهٔ برنامه با امضای اختصاصی انتشار.
- `kids-garden-1.0.0.bin`: خروجی ابزار رسمی بازار v0.1.14 برای همین AAB؛ در محل درخواست BIN در پنل بازار بارگذاری شود.
- `kids-garden-1.0.0.apk`: نسخهٔ قابل نصب با همان گواهی انتشار.

امضای APK و AAB بررسی و تولید BIN با موفقیت تمام شده است. گزارش و هش فایل‌ها کنار خروجی‌هاست. در پنل بازار چیزی بارگذاری نشده است. تغییر AAB به تولید دوبارهٔ BIN نیاز دارد.

کلید خصوصی و رمز در این مخزن نیستند. پشتیبان خصوصی خارج از مخزن تهیه شده و دریافت و نگهداری آن توسط مالک هنوز تأیید نشده است. پیش از اولین بارگذاری باید پشتیبان کلید و رمز را دریافت و امن نگهداری کنید. به‌روزرسانی‌های آینده باید با همین کلید امضا شوند. برای گوگل‌پلی نیز راهبرد مالکیت همین کلید با Play App Signing هماهنگ شود.

شناسهٔ فعلی برنامه `com.fayazamir.kidsgarden` است؛ پیش از ثبت اولیه آن را بررسی کنید. اطلاعات ناشر، سیاست عمومی حریم خصوصی و پذیرش روی گوشی واقعی همچنان باید تکمیل شوند. این مرحله فقط امضا و تولید خروجی موردنیاز بازار است، نه تأیید کیفیت یا پذیرش فروشگاه.

گواهی این نسخه با APK آزمایشی قبلی فرق دارد. اگر نسخهٔ آزمایشی نصب است، برای نصب APK انتشار ابتدا آن را حذف کنید؛ تنظیمات محلی نسخهٔ آزمایشی پاک می‌شود.

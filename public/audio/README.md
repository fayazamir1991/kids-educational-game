# صدای واقعی حیوانات

همهٔ ۱۷ صدای MP3، ضبط واقعی حیوان‌اند. فایل‌های مصنوعی قبلی حذف شده‌اند.

برای عنوان ضبط اصلی، نام ضبط‌کننده و لینک منبع و مجوز، ATTRIBUTIONS.md و sources.json را ببینید. منابع از آینه‌های مستند GitHub با نسخهٔ ثابت دریافت شده‌اند؛ دسترسی مستقیم به برخی سایت‌های اصلی در محیط محدود بود.

قطعه‌ها کوتاه شده، بلندی صدا یکدست و ابتدا/انتها نرم شده است. دو صدای کوتاه میمون و الاغ با فاصلهٔ سکوت تکرار شده‌اند. جزئیات پردازش و SHA256 برای هر فایل در sources-farm.json و sources-wild.json ثبت است.

مجوز مجموعهٔ واسط ESC-50 با مجوز هر ضبط اصلی یکسان نیست؛ notice کامل آن در ESC-50-LICENSE.txt حفظ شده است. مجوز صوت و فونت از مجوز کد برنامه جداست.

برای بررسی صحت دارایی‌ها و اعتباردهی: npm run test:audio

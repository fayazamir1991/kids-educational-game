# کی صدا کرد؟ — دنیای صداها

بازی شنیداری فارسی برای کودک حدود سه سال، با ۱۷ حیوان و صدای ضبط‌شدهٔ واقعی. صفحه فقط خود بازی است و برای موبایل افقی طراحی شده: سه تصویر بزرگ، دکمهٔ شنیدن دوباره، گل‌های تشویقی و ابزار کوچک تنظیمات. در حالت عمودی، راهنمای چرخاندن گوشی نمایش داده می‌شود.

حیوانات: گاو، گوسفند، جوجه، کلاغ، میمون، شیر، مگس، زنبور، خروس، مرغ، اسب، الاغ، سگ، گربه، اردک، خوک و قورباغه.

در هر سؤال سه حیوان متفاوت به‌صورت تصادفی از کل مجموعه انتخاب می‌شوند؛ پاسخ درست حتماً بین آن‌هاست. پاسخ هدف در پنج سؤال یک بازی تکرار نمی‌شود. مگس و زنبور به‌علت شباهت وزوز، در یک سؤال کنار هم قرار نمی‌گیرند. پس از پاسخ درست، سؤال و صدای بعدی خودکار آغاز می‌شود. پاسخ اشتباه، جریمه یا زمان‌سنج وجود ندارد. پخش اول با لمس کودک شروع می‌شود تا محدودیت پخش خودکار مرورگرهای موبایل رعایت شود.

## اجرا و ساخت

Node.js نسخهٔ 22.12 یا جدیدتر لازم است (محیط توسعه: نسخهٔ 24).

```sh
npm ci
npm run dev
```

سرور توسعه به‌طور پیش‌فرض روی پورت 5173 و تمام رابط‌های شبکه اجرا می‌شود. برای نسخهٔ وب نهایی:

```sh
npm run build
npm run preview
```

محتوای `dist` قابل انتشار روی میزبان ایستا است. سرور پشتیبان، پایگاه داده، کلید محرمانه، ثبت‌نام، تبلیغات و ابزار تحلیل رفتار در کار نیست. فونت، تصاویر و صداها محلی‌اند. نسخهٔ وب فایل صوتی هر حیوان را هنگام نیاز بارگذاری و در حافظه رمزگشایی می‌کند؛ هیچ سرویس صوتی بیرونی در زمان بازی فراخوانی نمی‌شود.

## نسخهٔ تک‌فایلی

```sh
npm run build:standalone
```

`dist/little-farm.html` همهٔ ۱۷ صدا، تصویرها و فونت را در خودش دارد. فایل را پس از دانلود در مرورگر باز کنید؛ برای خود بازی نصب Node یا اینترنت لازم نیست. پیش‌نمایش فایل در چت یا برنامهٔ Files بعضی گوشی‌ها ممکن است جاوااسکریپت را اجرا نکند و باید فایل با مرورگر باز شود. دانلود و تحویل فایل از پنل، به اتصال محیط در سرویس وابسته است؛ ساخت موفق فایل تضمینِ دسترس‌پذیر بودن دانلود از رابط سرویس نیست.

## صداها و ذکر منبع

فایل‌های مصنوعی قبلی حذف شده‌اند. صداهای فعلی از ضبط‌های BigSoundBank و Freesound، از طریق آینه‌های GitHub با منابع و مجوز مستند، تهیه شده‌اند. قطعه‌ها کوتاه شده، بلندی صدا به حدود ‎-20 LUFS و سقف قله ‎-3 dBTP تنظیم شده و ابتدا/انتهای ملایم دارند. فایل‌ها MP3 تک‌کاناله 44.1 kHz / 128 kbps هستند. هیچ تغییر زیر و بمی برای ساخت صدای حیوان یا تولید مصنوعی صدای حیوان انجام نشده است. دو کلیپ کوتاه میمون و الاغ با فاصلهٔ سکوت تکرار شده‌اند؛ جزئیات دقیق پردازش برای هر ضبط در فراداده آمده است.

اطلاعات ضبط اصلی، نام ضبط‌کننده، مجوز، لینک مدرک مجوز، آینهٔ نسخهٔ مشخص و SHA256 در این فایل‌ها ثبت است:

- `public/audio/sources-farm.json`
- `public/audio/sources-wild.json`
- `public/audio/sources.json`

همین اعتباردهی در بخش تنظیمات «منابع و مجوز صداها» قابل مشاهده است. مجوز دارایی‌های صوتی از کد برنامه جداست؛ فایل‌های مجوز مجموعه‌های واسط، از جمله ESC-50، نیز باید در توزیع دارایی‌ها رعایت شوند. جزئیات در `public/audio/README.md` و `public/audio/ATTRIBUTIONS.md` است.

تنظیم بلندی صدا، خاموش کردن صدا، شروع دوباره و تمام‌صفحه از ابزارهای بالای بازی در دسترس‌اند. در مرورگرهای پشتیبان، دکمهٔ تمام‌صفحه تلاش می‌کند جهت صفحه را افقی قفل کند. در بقیهٔ مرورگرها چرخاندن فیزیکی دستگاه کافی است. تشویق گفتاری فارسی فقط در صورت نصب صدای `fa` دستگاه از Web Speech API استفاده می‌کند؛ پخش صداهای حیوانات به آن وابسته نیست.

تنها بلندی صدا و ترجیحات در `localStorage` ذخیره می‌شوند؛ پاسخ‌های کودک ذخیره نمی‌شوند. کار با صفحه‌کلید، برچسب‌های دسترس‌پذیر، پنجره‌های محاوره‌ای بومی و `prefers-reduced-motion` پشتیبانی می‌شوند.

## بررسی

```sh
npm test
npm run test:audio
npm run test:e2e
npm run test:standalone
```

- آزمون منطق بازی، ۱۰۰۰ بذر تصادفی، تنوع حیوانات، سه گزینهٔ یکتا، حضور پاسخ درست و حذف سؤال‌های مبهمِ زنبور/مگس را بررسی می‌کند.
- ساخت، صحت هش تمام صداها و تطابق مجوز و اعتباردهی داخل بازی را بررسی می‌کند.
- آزمون مرورگر، رمزگشایی و پخش واقعی MP3 با Web Audio، پنج سؤال و تغییر تصادفی گزینه‌ها، تکرار صدا، تنظیمات، شروع مجدد و اندازه‌های افقی 667×375، 844×390 و 915×412 را بررسی می‌کند؛ پخش خودکار در آزمون به‌زور فعال نشده است.
- آزمون نسخهٔ مستقل همهٔ ۱۷ فایل صوتی را رمزگشایی کرده و محتوای غیرصامت و نبود بریدگی قله را بررسی می‌کند؛ همچنین کل بازی و بارگذاری دارایی‌ها را با شبکهٔ خاموش آزمایش می‌کند.

Chromium در `/usr/bin/chromium` استفاده می‌شود؛ مسیر را می‌توان با متغیر `CHROMIUM_PATH` تغییر داد. سیاست مرورگر این محیط، باز کردن مستقیم `file://` را محدود می‌کند، بنابراین آزمون مستقل به‌طور پیش‌فرض محتوای همان HTML را با `page.setContent` اجرا می‌کند. روی دستگاهی با اجازهٔ باز کردن فایل محلی می‌توانید `STANDALONE_FILE_NAVIGATION=1 node tests/standalone-smoke.mjs` را اجرا کنید. فایل‌های نتیجه در `test-results/standalone` قرار می‌گیرند.

شخصیت‌های SVG اختصاصی‌اند و پس‌زمینه برای همین پروژه تولید شده است. فونت Vazirmatn با مجوز OFL از `@fontsource/vazirmatn` تأمین می‌شود.
